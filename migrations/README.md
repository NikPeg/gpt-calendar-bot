# Миграции базы данных

Эта папка содержит миграции для обновления структуры базы данных.

## 📝 Текущее состояние

На данный момент все старые миграции удалены. Проект начинается с чистой структурой БД.

При необходимости изменения структуры базы данных, создавайте новые миграции в этой папке.

## 📋 Правила именования миграций

**ВАЖНО:** Все миграции должны иметь нумерацию для обеспечения правильного порядка применения.

### Формат имени файла

```
migration_NNN_description.py
```

Где:
- `NNN` - трёхзначный номер миграции (001, 002, 003, ...)
- `description` - краткое описание на английском языке в формате snake_case

### Примеры правильных имён

✅ **Правильно:**
- `migration_001_add_service_account.py`
- `migration_002_add_user_email.py`
- `migration_003_add_new_field.py`
- `migration_010_update_schema.py`

❌ **Неправильно:**
- `migration_add_service_account.py` (нет номера)
- `migration_1_add_field.py` (однозначный номер, должен быть 001)
- `migration_002AddField.py` (не snake_case)
- `migration_add_field.py` (нет номера)

### Правила нумерации

1. **Номера должны быть последовательными:** 001, 002, 003, ...
2. **Используйте трёхзначные номера:** всегда с ведущими нулями (001, не 1)
3. **Не пропускайте номера:** если удалили миграцию 003, переименуйте последующие
4. **При конфликте:** если нужно вставить миграцию между существующими, используйте промежуточные номера (например, 001, 002, 002a, 003) или переименуйте все последующие

### Структура файла миграции

Каждая миграция должна содержать функцию `upgrade()`:

```python
"""
Миграция: краткое описание на русском.
"""

import os

import aiosqlite
from dotenv import load_dotenv

load_dotenv()
DATABASE_NAME = os.environ.get("DATABASE_NAME", "users.db")


async def upgrade():
    """
    Описание того, что делает миграция.
    """
    async with aiosqlite.connect(DATABASE_NAME) as db:
        cursor = await db.cursor()
        
        # Ваш код миграции здесь
        
        await db.commit()
        return "Сообщение об успешном выполнении"
```

## 🚀 Использование

Миграции применяются автоматически при запуске бота. Вручную:

```bash
python -m migrations.migration_manager
```

## 📖 Как создать новую миграцию

1. Определите следующий номер (последний номер + 1)
2. Создайте файл `migration_NNN_description.py` в этой папке
3. Скопируйте структуру из существующей миграции
4. Реализуйте функцию `upgrade()`
5. Миграция будет применена автоматически при следующем запуске бота

## ⚠️ Важные замечания

- Миграции применяются в алфавитном порядке (благодаря сортировке по имени файла)
- Нумерация гарантирует правильный порядок применения
- Каждая миграция применяется только один раз (отслеживается в таблице `migrations`)
- Всегда проверяйте существование полей/таблиц перед их созданием
- Используйте транзакции для атомарности операций
