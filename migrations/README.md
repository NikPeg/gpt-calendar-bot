# Миграции базы данных

Эта папка содержит миграции для обновления структуры базы данных.

## 📝 Текущее состояние

На данный момент все старые миграции удалены. Проект начинается с чистой структурой БД.

При необходимости изменения структуры базы данных, создавайте новые миграции в этой папке.

## 🚀 Использование

Миграции применяются автоматически при запуске бота. Вручную:

```bash
python -m migrations.migration_manager
```

## 📖 Документация

Миграции применяются автоматически при запуске бота. Для создания новой миграции создайте файл `migration_XXX_description.py` в этой папке.
